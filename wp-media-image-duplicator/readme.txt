# WP Media Image Duplicator

Adds a Duplicate action for images in the WordPress Media Library.

## Installation

1. Upload/install `wp-media-image-duplicator.zip` from WordPress Admin → Plugins → Add New → Upload Plugin.
2. Activate the plugin.
3. Go to Media → Library.
4. Use List View and click "Duplicate" under an image.
5. In Grid View, select/open an image and use the Duplicate button when available.

The plugin creates a new physical copy of the image and a separate WordPress attachment.
